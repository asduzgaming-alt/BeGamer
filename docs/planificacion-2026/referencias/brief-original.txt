# 13. ARQUITECTURA TÉCNICA

La web deberá ser compatible con el hosting cPanel disponible y mantenerse mediante Git.

## Contexto de infraestructura previa

Anteriormente se trabajó en una web denominada Vialma Travel con:

- Desarrollo basado en React.
- Repositorio GitHub.
- Hosting Namecheap con cPanel.
- Gestión de dominio y DNS.
- Acceso SSH/Git para despliegue.
- Administración de archivos del hosting.

Este flujo sirve como referencia operativa.

No asumir que la cuenta o configuración de BeGamer tiene exactamente las mismas capacidades. Verificar el entorno.

No reutilizar credenciales, claves SSH ni archivos privados de Vialma Travel.

## Evaluación tecnológica obligatoria

Comparar:

**Opción A: Astro + React Islands**

- Páginas estáticas orientadas a SEO.
- Componentes React para la experiencia interactiva.
- Generación estática.
- Menor dependencia de JavaScript en páginas informativas.

**Opción B: React + Vite con prerenderizado**

- Arquitectura cercana al proyecto anterior.
- Componentes reutilizables.
- Generación de HTML por ruta mediante estrategia SSG.
- Integración de componentes 3D y animaciones.

**Opción C: Next.js con exportación estática**

- Rutas de páginas y contenido preconstruido.
- Evaluación de restricciones de exportación.
- Compatibilidad con hosting estático.

No elegir una arquitectura SSR con servidor Node permanente sin comprobar antes que cPanel soporte de manera adecuada ese despliegue.

### Stack interactivo a evaluar

- React.
- TypeScript.
- Three.js.
- React Three Fiber.
- GSAP.
- ScrollTrigger.
